API Console

Browse the API routes represented by files in functions/api/, select one, send a request, and inspect the HTTP status and response. This console calls the live website, not a simulated test server.

Important — live store: GET requests are usually for reading data, but each endpoint's code determines what it really does. POST/PUT/PATCH/DELETE requests may create orders, change products, send verification messages, call AliExpress/Paystack, or modify/delete database records. Test with care. Never paste passwords, API keys, access tokens, or customer secrets into the request body. Responses may contain private store/customer data.

API file catalogue

The catalogue lists the current known files in the repository, including the nested Paystack functions. The route is based on the Cloudflare Pages file-routing convention.

Request builder

For GET requests the body is ignored. Use valid JSON for other methods. Each API may require specific fields; an error response can help identify what is missing.
